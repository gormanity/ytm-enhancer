## Initial public beta

YTM Menu Bar brings YouTube Music playback details and controls to the macOS
menu bar. Through the optional Connected Apps (Beta) feature, it communicates
locally and privately with the YTM Enhancer extension in Google Chrome,
Chromium, Microsoft Edge, or Firefox to provide a native macOS experience.
Playback data never passes through external services.

### Highlights

- See the current track, artwork, progress, playback state, and upcoming track.
- Control play, pause, previous, next, seeking, shuffle, and repeat without
  returning to the browser.
- Open or focus YouTube Music directly from the menu bar.

Learn more and install from the
[YTM Menu Bar landing page](https://gormanity.github.io/ytm-enhancer/menu-bar/install.html).
