## Initial public beta

YTM Menu Bar brings YouTube Music playback details and controls to the macOS
menu bar through YTM Enhancer's optional Connected Apps feature.

### Highlights

- See the current track, artwork, progress, playback state, and upcoming track.
- Control play, pause, previous, next, seeking, shuffle, and repeat without
  returning to the browser.
- Open or focus YouTube Music directly from the menu bar.
- Connect through Google Chrome, Chromium, Microsoft Edge, or Firefox.
- Follow the active browser connection when more than one supported browser is
  running.
- Match the current macOS appearance and receive update notices from the About
  window.
- Keep playback communication local between the extension and the native app.

### Get started

Install the signed and notarized direct package, or install through Homebrew.
Then enable Connected Apps and YTM Menu Bar in the YTM Enhancer extension.
