## Initial public beta

YTM Enhancer CLI brings YouTube Music playback information and controls to macOS
and Linux terminals through YTM Enhancer's optional Connected Apps feature.

### Highlights

- Inspect playback with `status`, `now`, and the live `watch` view.
- Control play, pause, toggle, previous, next, seeking, shuffle, and repeat.
- Open or focus YouTube Music without leaving the terminal.
- Use JSON and line-oriented output in scripts and shell integrations.
- Diagnose the browser connection and native host with `doctor` and `daemon`.
- Connect through supported Chromium-family browsers or Firefox.
- Install prebuilt native binaries without installing Go or using `sudo`.
- Keep playback communication local without sharing YouTube credentials.

### Get started

Download the package for your operating system and architecture, extract it, and
run `./install.sh`. Then enable Connected Apps and YTM Enhancer CLI in the
browser extension.
