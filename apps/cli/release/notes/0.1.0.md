## Initial public beta

YTM Enhancer CLI brings YouTube Music playback information and controls to macOS
and Linux terminals. Through the optional Connected Apps (Beta) feature, it
communicates locally and privately with the YTM Enhancer extension in Google
Chrome, Chromium, Microsoft Edge, Brave, or Firefox to provide native terminal
controls. Playback data never passes through external services, and the CLI
never requires your YouTube credentials.

### Highlights

- Inspect playback with `status`, `now`, and the live `watch` view.
- Control play, pause, toggle, previous, next, seeking, shuffle, and repeat.
- Open or focus YouTube Music without leaving the terminal.
- Use JSON and line-oriented output in scripts and shell integrations.
- Diagnose the browser connection and native host with `doctor` and `daemon`.
- Install prebuilt packages without installing Go or using `sudo`.

Learn more and install from the
[YTM Enhancer CLI landing page](https://gormanity.github.io/ytm-enhancer/cli/).
