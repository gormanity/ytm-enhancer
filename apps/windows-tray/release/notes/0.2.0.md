## Initial public beta

YTM Tray brings YouTube Music playback details and controls to the Windows
system tray. Through the optional Connected Apps (Beta) feature, it communicates
locally and privately with the YTM Enhancer extension in Google Chrome,
Microsoft Edge, or Firefox to provide a native Windows experience. Playback data
never passes through external services.

### Highlights

- See the current track, artwork, progress, playback state, and upcoming track.
- Control play, pause, previous, next, seeking, shuffle, and repeat without
  returning to the browser.
- Open or focus YouTube Music directly from the tray.

Learn more and install from the
[YTM Tray landing page](https://gormanity.github.io/ytm-enhancer/windows-tray/install.html).
