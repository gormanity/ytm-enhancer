## Initial public beta

YTM Tray brings YouTube Music playback details and controls to the Windows
taskbar through YTM Enhancer's optional Connected Apps feature.

### Highlights

- See the current track, artwork, progress, playback state, and upcoming track.
- Control play, pause, previous, next, seeking, shuffle, and repeat without
  returning to the browser.
- Open or focus YouTube Music directly from the tray.
- Connect through Google Chrome, Microsoft Edge, or Firefox.
- Install one signed package that automatically selects x64 or ARM64.
- Check for signed, checksum-verified updates from the About window.
- Install and uninstall through normal Windows app-management surfaces.
- Keep playback communication local between the extension and the native app.

### Get started

Download and run `YTM-Tray-0.2.0-Setup.exe`. Then enable Connected Apps and YTM
Tray in the YTM Enhancer extension.
